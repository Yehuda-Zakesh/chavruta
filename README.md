# חברותא

סנכרון מקום הלימוד בין שני מחשבים שפתוחה בהם [אוצריא](https://github.com/otzaria/otzaria).
אחד עובר דף — השני עובר איתו, בזמן אמת, דרך הרשת המקומית בלבד: אותו ראוטר,
בלי אינטרנט, בלי שרת חיצוני ובלי חשבון.

## איך זה בנוי

שני חלקים:

| חלק | מה זה | למה |
|-----|-------|-----|
| [`companion/`](companion/) | תוכנית Dart קטנה שרצה ברקע על כל מחשב | תוסף אוצריא רץ ב-WebView ואינו יכול לפתוח סוקט UDP או להאזין לרשת. המתאם עושה את זה בשבילו. |
| [`plugin/`](plugin/) | תוסף אוצריא (`.otzplugin`) | קורא את מקום הקריאה מאוצריא, שולח אותו למתאם, ומנווט כשהחברותא זזה. |

```
אוצריא (מחשב א)                                    אוצריא (מחשב ב)
  └─ תוסף חברותא                                     └─ תוסף חברותא
        │ HTTP על 127.0.0.1                                │
        ▼                                                  ▼
   מתאם חברותא  ◄──── UDP broadcast ברשת המקומית ────►  מתאם חברותא
                        (פורט 45870, חתום HMAC)
```

- **התוסף אל המתאם**: HTTP על loopback בלבד, בפורט הראשון הפנוי בטווח
  45871–45875. התוסף סורק את הטווח ומזהה את המתאם לפי `/hello` — אין
  קונפיגורציה שצריך לתחזק.
- **המתאם אל המתאם**: UDP broadcast על פורט 45870. אין שרת ואין כתובות IP
  להקליד: כל מתאם משדר לכל הרשת, וכל אחד מסנן לפי החדר שלו.

## קוד החברותא והאבטחה

שני הצדדים מקלידים אותו **קוד חברותא** (מלה או משפט). הקוד עצמו אינו נשלח
לרשת. מכל הודעה נשלחים:

- **גיבוב** של הקוד (16 תווים) — לסינון מהיר של הודעות מחדרים אחרים.
- **חתימת HMAC-SHA256** על תוכן ההודעה, במפתח שנגזר מהקוד — הוכחה שהשולח
  יודע את הקוד, ומניעת שינוי ההודעה בדרך.

בנוסף: חלון טריות של חמש דקות (מונע שליחה חוזרת של הודעה שנקלטה), השוואת
חתימות בזמן קבוע, וסינון הודעות כפולות או מאוחרות לפי מונה וחותמת זמן.

הקוד מנורמל בשני הצדדים (רווחים כפולים, רווחים מהקצה, רישיות לטיניות), כדי
ששתי הקלדות של אותו קוד יגיעו לאותו חדר.

> קוד החברותא הוא הסוד היחיד שמגן על החיבור. בחרו משפט שאינו ניחוש מובן
> מאליו, בדיוק כמו סיסמה קצרה.

## התקנה

1. **המתאם** — הריצו את `chavruta-companion-<גרסה>-windows.exe`. הוא מתקין
   את המתאם, מרשם אותו לעלייה עם המשתמש (בלי חלון קונסולה), ומצרף את קובץ
   התוסף.
2. **התוסף** — התקינו את `chavruta-<גרסה>.otzplugin` באוצריא (לחיצה כפולה,
   או "התקנת תוסף מקובץ" במסך התוספים).
3. **הרשאות** — אשרו לתוסף את `ריצה בעליית אוצריא` ו-`המשך ריצה ברקע`.
   בלעדיהן הסנכרון עובד רק כשלשונית התוסף פתוחה, והתוסף אומר לכם את זה.
4. **זיווג** — בשני המחשבים: לשונית "חברותא" ← אותו קוד ← "התחברות".

## שימוש יומיומי

אחרי הזיווג אין מה לעשות. פותחים ספר, וכשאחד מכם עובר מקום השני עובר איתו.
לשונית התוסף מראה מי מחובר, איפה כל אחד נמצא, ואם המתאם פועל.

מקום מסונכרן לפי **שם הספר והקטע** ולא לפי מזהה מספרי, כי המזהה המספרי שונה
בין מחשב למחשב לפי סדר האינדוקס של הספרייה. ספר שאינו קיים בספרייה של הצד
השני — התוסף אומר זאת ולא מנווט.

## פיתוח

דרישות: Dart SDK 3.4+ (או Flutter), ולאריזת התוסף — אוצריא 0.9.97 ומעלה
מותקנת. למתקין — [Inno Setup 6](https://jrsoftware.org/isdl.php).

```powershell
# בנייה מלאה: מתאם, תוסף, מתקין ← dist\
.\tool\build.ps1

# רק המתאם, בלי אריזה ובלי מתקין
.\tool\build.ps1 -SkipPlugin -SkipInstaller
```

### המתאם

```bash
cd companion
dart pub get
dart test          # 67 בדיקות: פרוטוקול, hub, קונפיג, API מקומי
dart analyze

# הרצה מקומית
dart run bin/chavruta_companion.dart --room "דף יומי" --name "המחשב שלי"
dart run bin/chavruta_companion.dart --help
```

הקונפיג והלוג יושבים ב-`%LOCALAPPDATA%\Chavruta`. אפשר להפנות אותם ל-
`--data-dir` אחר, וכך גם להריץ שני מתאמים על מחשב אחד לבדיקה — הם ייקחו שני
פורטים שונים ב-loopback וימצאו זה את זה ב-broadcast.

### התוסף

מצב פיתוח באוצריא טוען את התוסף ישירות מהתיקייה `plugin/` — אין צורך לארוז
בכל שינוי. לאריזה ולולידציה (מניפסט, הרשאות, תאימות עיצוב):

```powershell
otzaria pack-plugin .\plugin --force -o .\dist\chavruta.otzplugin
```

### ה-API המקומי של המתאם

| נתיב | מה עושה |
|------|---------|
| `GET /hello` | זיהוי המתאם ומצבו: גרסה, זיווג, מחוברים, מיקום מרוחק אחרון. |
| `GET /events?since=<seq>` | המתנה ארוכה (עד 25 שניות) לעדכון מהחברותא. |
| `POST /publish` | דיווח על מקום הלימוד המקומי: `{bookId, index, ref}`. |
| `POST /room` | כניסה לחברותא או יציאה ממנה: `{code}` (או `null`). |
| `POST /name` | שינוי שם המכשיר: `{name}`. |

השרת מאזין ב-`127.0.0.1` בלבד ואינו נגיש מהרשת.
