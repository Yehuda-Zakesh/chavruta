# תיקוני חיבור וחוויית שימוש

## תקלות שתוקנו

- כשל בשליחת הנוכחות הראשונה עצר את האתחול לפני התקנת טיימרי ההגדרות והמצב. האתחול ממשיך כעת, ומנגנון התעבורה מטפל בניסיון החוזר.
- עצירה בזמן כתיבת המחזיק אפשרה לאתחול להמשיך עם מנוע שכבר נמחק. בודקים שוב את זהות המנוע לאחר ההמתנה.
- כשל רגעי בקריאת אחסון הוצג כחדר ריק או רשימת מחוברים ריקה. התצוגה שומרת את הערך האחרון שנקרא בהצלחה; יציאה אמיתית עדיין מתעדכנת. כשאין ערך קודם, הכשל מוצג במקום להמציא מצב ריק.
- חזרת הרשת משדרת מיד נוכחות וספרים, בלי להמתין לפעימה התקופתית.
- שינוי הגדרות מסומן כמוחל רק לאחר שהפעולה הצליחה, כדי שכשל זמני יאפשר ניסיון חוזר.
- הודעת הסגירה משתמשת ב־`tapOpenPlugin`, שמוסר את האירוע ללשונית במקום למופע הרקע. הדף מציג את כפתורי ההחלטה גם כשהפתיחה התחילה ממסך הבית.
- כשל בסגירת חלק מהספרים אינו מוצג כהצלחה מלאה; אפשר לנסות שוב. כשל באישור השארת ספר פתוח אינו נבלע בשקט.

## מסכים ופעולות

מסך הבית מציג שתי אפשרויות במרכז: חיבור מרחוק וחיבור באמצעות מתאם. פרטי החיבור מופיעים לאחר בחירה, והגדרות סנכרון המקום, מדיניות הסגירה ושם המכשיר נמצאות בכפתור ההגדרות. בחירת הבית אינה מנתקת חברותא קיימת. הצעת העברת ספרים או לחיצה על הודעת סגירה פותחות את מסך החיבור כדי לא להסתיר פעולה שממתינה לתשובה.

בחירת דרך החיבור הוסרה מתוך מסך החיבור; מעבר בין הדרכים מתבצע באמצעות שני האריחים בדף הבית בלבד. בשאלת סגירת ספרים יש שורה לכל ספר עם שתי אפשרויות: לסגור גם כאן או להשאיר פתוח. החלטה על ספר אחד אינה מסירה את השאלות על הספרים האחרים; אם הפעולה נכשלת, השורה נשארת לניסיון חוזר. פעולות הסגירה מבוצעות בתור כדי לא ליצור התנגשות בין אינדקסי טאבים.

כרטיס המוכנות מציג הרשאות חיבור וסנכרון, מנוע פעיל והרשאות רקע, זמינות שרת הממסר או הקישור המקומי, גרסת אוצריא וגרסת התוסף. המחשב השני מדווח את המצב שלו בהודעת `ready` חתומה ונפרדת מהודעות הסנכרון הרגילות. גרסאות ישנות מתעלמות מסוג ההודעה הנוסף וממשיכות לסנכרן; התצוגה מציינת שהאבחון אינו זמין. אין שינוי בחתימות ההודעות הקיימות או בגרסת הפרוטוקול. השוואת גרסאות שונות מציגה המלצת עדכון, ואינה טוענת שכל פער גרסאות מונע סנכרון.

דיווח מוכנות נשלח עם פעימת הנוכחות; זמן הקבלה המקומי נשמר בנפרד מהנוכחות. דיווח שלא עודכן במשך 70 שניות אינו מוצג כמוכנות תקינה. העברת המנוע בין הלשונית לרקע אינה מרעננת את גיל הדיווח של החברותא. בחיבור באמצעות מתאם, אבחון שני הצדדים דורש גם מתאם מעודכן בשני המחשבים. ההרשאות נלקחות מאירוע האתחול של אוצריא; לאחר שינוי הרשאות יש לטעון את התוסף מחדש אם אוצריא לא עשתה זאת בעצמה.

הורדת המתאם פותחת את דף ה־Release האחרון ב־GitHub דרך `app.openUrl`. נוספת הרשאת `app.open_url`; משתמשים קיימים עשויים להידרש לאשר אותה באוצריא. ההתקנה נעשית לאחר ההורדה בדפדפן.

הדיווח משתמש ב־`feedback.report` ובאישור המובנה של אוצריא. התוסף מציג בנפרד הצלחה, שמירה בתור, ביטול וכשל. ביטול או כשל משאירים את התיאור לעריכה. מצורפים התיאור ודרך החיבור, ללא צירוף אוטומטי של קוד החברותא.

## אימות

- גרסת אוצריא המינימלית הוגדרה ל־0.9.99; בדיקת המוכנות והודעות העדכון משתמשות באותו סף.
- דיווחי מוכנות אינם מקדמים את סף סינון הודעות הסנכרון. בדיקות רגרסיה בשתי השפות מכסות מקום ונוכחות שמגיעים אחרי דיווח מוכנות חדש יותר, כפילות דיווח ופרידה.
- הכותרת גדלה לפי מספר השורות בחלון צר, כדי ששורת המצב לא תכסה את התוכן.
- בדיקות Node כוללות שחזור כשל בהכרזת הנוכחות הראשונה, עצירה באמצע האתחול, שגיאות אחסון בתצוגה, חזרת הרשת, הודעת סגירה וסגירה חלקית.
- בדיקות השילוב רצות עם שרת הממסר המקומי, כולל העברת מנוע בין לשונית לרקע, החלפת חדרים, פרידה ותורים עמידים. ראו הוראות ב־`plugin-test/remote-link.test.js`.
- נבדקו בדפדפן Edge המסכים, פתיחת קישור ההורדה, דיווח וביטול דיווח, אישור סגירה ופריסה ברוחבים 320, 390, 520 ו־800 פיקסלים, עם גשר אוצריא מדומה. שורת המצב נשארת בתוך הכותרת בכל הרוחבים. לא נשלח דיווח אמיתי.
- עדיין דרושה בדיקה ידנית בתוך אוצריא בשני מחשבים, במיוחד מעבר לשולחן המשותף, הרשאות הרקע ומעבר לחיבור אינטרנט אחר. הבדיקות האוטומטיות אינן מאמתות את מחזור החיים של שני WebView בתוך אוצריא עצמה.

## רעיונות להמשך

1. כפתור העתקת הזמנה לחברותא, עם דרך החיבור וקוד שהמשתמש בחר לשתף במפורש.
2. **מומש:** אישור סגירה ליד שם כל ספר, כך שאפשר להשאיר ספר אחד ולסגור אחר.
3. **מומש:** בדיקת מוכנות בשני הצדדים: הרשאות, רקע, זמינות השרת והתאמת גרסאות.
4. כפתור חזרה לחברותא פעילה במסך הבית, עם מספר המחוברים, אם רוצים להרחיב בעתיד את הדרישה לשני אריחים בלבד.
